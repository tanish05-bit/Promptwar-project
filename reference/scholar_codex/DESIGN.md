## Brand & Style

This design system establishes an atmospheric, contemplative environment blending the intellectual rigor of a late-night archival study with the focused ergonomics of high-performance prompt engineering. The aesthetic intersects tactile mid-century academic apparatus and modern digital workspaces: leather-bound notebooks, card catalogs, and drafting tables translated into purposeful, distraction-free interfaces.

The emotional signature is focused, dignified, and tactile. Interface elements evoke physical scholarly artifacts—index dividers, catalog tabs, linen textures, and warm terminal readouts—avoiding cartoonish skeuomorphism in favor of disciplined physical metaphors. Users should feel like competitive linguists and archival logicians operating within a high-stakes, private research lab.

## Colors

The palette draws from aged amber resins, oxidized book cloth, and nocturnal drafting rooms. The atmosphere relies on deep, non-harsh obsidian tones rather than pure cold blacks, maintaining warmth across all surfaces.

### Surface Tiers
- **Canvas Base (`#161618`):** The foundational void; an ink-stained obsidian base.
- **Surface Layer 1 (`#1e1e22`):** Primary desk plane for sidebars, secondary panels, and structural docks.
- **Surface Layer 2 (`#26252b`):** Workcards, editor tiles, dossier containers, and interactive stages.
- **Surface Elevated (`#2f2e36`):** Active sheets, dropdowns, floating palettes, and focused workspaces.

### Ink & Parchment Typography
- **Parchment Primary (`#f0ede6`):** Primary text, high-legibility prompt outputs, titles.
- **Vellum Secondary (`#dcd7ce`):** Body copy, metadata labels, structural titles.
- **Lead / Slate Muted (`#a39e93`):** Captions, parameter timestamps, auxiliary hints.
- **Graphite Disabled (`#5c5953`):** Inactive states, placeholder cues, rule demarcations.

### Accents & Semantic Signals
- **Amber Resin (`#d97736`):** Primary focus action, run/execute triggers, active battle indicator.
- **Gilded Sepia (`#e5a968`):** Highlighting, token counter readouts, warning markers.
- **Sage Verdigris (`#4d9375`):** Success states, benchmark wins, optimal evaluation metrics.
- **Celestial Indigo (`#6b8afd`):** Model comparisons, branching diffs, external lineage links.
- **Bordeaux Crimson (`#c85a53`):** Syntax violations, run breaks, loss indicators.

### Structural Lines
- **Border Subtle (`#2e2d35`):** Subdued panel framing and baseline dividers.
- **Border Articulated (`#3a3942`):** Tab borders, active container edges, and keyboard focus perimeters.

## Typography

The typographic hierarchy establishes a deliberate contrast between scholarly literary tradition and precise technical execution:

- **Headlines & Editorial Titles (Literata):** Brings literary gravity and reading comfort. It anchors prompt titles, match summaries, and historical session logs with editorial authority.
- **Interface & Operational Text (Be Vietnam Pro):** Crisp, humanist, and balanced sans-serif optimized for long prompting sessions, interface dialogues, and density without cognitive fatigue.
- **Data, Metadata & Code (JetBrains Mono):** Provides machine-grade legibility for prompt token metrics, latency outputs, parameter weights, keyboard shortcuts, and code blocks.

## Layout & Spacing

The layout is built around a split-bench workstation model capable of fluid lateral comparison. 

### Grid & Layout Systems
- **Desktop (1200px+):** Asymmetrical 12-column dynamic framework. Standard layout features a 3-column archival index (prompts history, active leagues), a 5-column primary codex input arena, and a 4-column output / evaluation bench. Gutters remain fixed at `1.25rem` (`20px`) with `2rem` (`32px`) margins.
- **Tablet (768px - 1199px):** 8-column layout. Archival index collapses into a slide-over panel; prompt editor and output inspector enter a tabbed or side-by-side split screen.
- **Mobile (<768px):** 4-column stacked configuration. Workspaces shift to a single active sheet model. Transitions between prompt writing and arena output happen via indexed bottom sheet switches.

### Rhythmic Density
Spacing strictly honors compact, scholarly density:
- Use `space-xs` (4px) and `space-sm` (8px) for related metadata pairs, token flags, and internal control padding.
- Use `space-md` (16px) for interior card gutters and form groupings.
- Use `space-lg` (24px) and `space-xl` (40px) for panel separation and dossier framing.

## Elevation & Depth

Visual hierarchy uses physical sheet-layering and subdued ambient illumination rather than synthetic drop shadows.

- **Level 0 (Desk Mat):** `#161618`. Absolute background; non-elevated ground plane.
- **Level 1 (Folio Panel):** `#1e1e22` bordered by `#2e2d35`. Subtle inset appearance, flat against the canvas.
- **Level 2 (Dossier Card / Active Pane):** `#26252b` encased in `#3a3942`. Supported by an ultra-soft, warm ambient shadow: `0 4px 16px -2px rgba(10, 9, 12, 0.45)`.
- **Level 3 (Tactile Sticky Note / Overlay):** `#2f2e36` or contextual muted sepia tint. Casts a dual shadow: a crisp contact shadow (`0 2px 4px rgba(0,0,0,0.5)`) plus a diffuse under-glow (`0 8px 24px -4px rgba(0,0,0,0.6)`).
- **Physical Details:** Borders are strictly 1px with low contrast. High-elevation states utilize a 1px top highlight (`rgba(240, 237, 230, 0.05)`) simulating overhead desk-lamp illumination across the upper rim of paper and panels.

## Shapes

The shape system adopts a tailored, sharp-cornered bookbinder aesthetic:

- **Radius (0.25rem / 4px):** Applied to inputs, buttons, chips, and small panels to retain a crisp, utilitarian structure reminiscent of punch cards and stamped tags.
- **Folder Tabs & Notebook Ears:** Top edges of workspace headers utilize asymmetric rounding (`4px 4px 0px 0px`) or angled 45-degree corner bevels (2px cut) for tabbed views, reinforcing the archival filing metaphor.
- **Sticky Elements:** Ephemeral notes, model score slips, and contextual callouts retain strict `2px` corners with an optional organic micro-rotation (`-0.5deg` to `0.5deg`) when floating above the strict grid.

## Components

### Buttons & Action Controls
- **Primary (Execute / Submit Prompt):** Deep amber surface (`#d97736`) with dark typography (`#161618`), font weight 600. 1px inset rim highlight. On hover, shifts to `#e5a968` with crisp 1px displacement downward.
- **Secondary (Inspect / Fork):** Background `#26252b`, border 1px `#3a3942`, text `#f0ede6`. Hover triggers border change to `#a39e93`.
- **Ghost (Archival Action):** Transparent background, text `#a39e93`, hover background `#1e1e22` with text `#f0ede6`.

### Inputs & Prompt Terminals
- **Prompt Canvas:** Multi-line text field set in `#1e1e22` with border `#2e2d35`. Monospaced text entry with parchment color (`#f0ede6`). Focused state uses a 1px border of `#d97736` without thick glow rings; instead, the container gains a subtle internal illumination.
- **Parameter Dials & Sliders:** Sleek horizontal brass grooves (`#2e2d35`) with `#d97736` active fill and a knurled rectangular scrub head (`#dcd7ce`).

### Nostalgic Folder Tabs
- Tab bar sits flush against the top edge of workspace containers.
- Inactive tabs display background `#161618`, border `#2e2d35`, and muted text `#a39e93`.
- Active tab merges seamlessly with the container below (`#26252b`), bordered on left, top, and right by `#3a3942`, with a 2px top accent line in `#d97736`.

### Sticky Notes & Scholar Callouts
- Secondary floating notes used for prompt critique, peer feedback, or token diffs.
- Background uses tinted slate-sepia (`#2b2823`), text `#e5a968`, with a faint left-border stroke (`3px solid #d97736`).

### Checkboxes, Radios & Switches
- **Checkboxes:** 14px square boxes, `#1e1e22` with `#3a3942` border. Checked state renders a brass-amber solid fill with a dark checkmark.
- **Toggle Switches:** Recessed pill track (`#1e1e22`) with an articulated tactile toggle block that slides smoothly into amber illumination when engaged.

### Badges & Metatags
- Rendered in JetBrains Mono (`label-sm`).
- Bordered rectangular pills (`1px solid #3a3942`) with `#1e1e22` background.
- Semantic indicators: Green tint for win-rates (`#4d9375`), amber for token usage (`#d97736`), and violet for temperature/lineage indicators (`#6b8afd`).
